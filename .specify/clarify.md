# قرارات Clarify

| الموضوع | القرار القابل للاختبار |
|---|---|
| الموقع | يعتمد التطبيق ولاية جزائرية محفوظة أو GPS يختاره المستخدم، ولا يعرض الجزائر كقيمة ثابتة إذا كان المصدر GPS أو ولاية أخرى. |
| الإمساك | يعرض وقت الفجر ناقص 10 دقائق كإمساك محلي، وتظهر البطاقة فقط في رمضان. |
| الإفطار | يساوي وقت المغرب المحسوب محليًا للموقع الحالي. |
| الأذان | يحتاج إلى ضغط المستخدم لتجاوز سياسة الصوت، وتبقى الأتمتة اختيارية من الإعدادات. |
| القبلة | يستخدم اتجاه الهاتف الحقيقي، وتظهر صورة الكعبة فقط عند المحاذاة ضمن الهامش المستقر. |
| رمضان | يُكتشف بالشهر الهجري التاسع وفق Islamic Umm al-Qura، ولا تظهر البطاقة خارجه. |
| Offline | يجب أن تتضمن قائمة Cache الملفات المعدلة والبيانات المحلية وملف الصوت. |
| النشر | لا يُرفع أي إصلاح بعد Analyze إلا بعد موافقة صريحة على تقريره، ثم يُختبر رابط GitHub Pages. |
| الهاتف | يلزم اختبار حقيقي لاحقًا للمستشعر والاهتزاز وGPS وسياسة الصوت؛ لا يُستنتج نجاحها الكامل من المحاكاة فقط. |
