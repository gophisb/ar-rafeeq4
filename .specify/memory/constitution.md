# دستور إغلاق الرفيق 4

## المبادئ الثابتة

يحافظ المشروع على بنية SPA الحالية المبنية بـ Vanilla JS وHTML وCSS، وعلى هوية Glass UI وRTL والتوافق مع Android وPWA.

تظل البيانات الدينية محلية، وتشمل القرآن العثماني وتفسير السعدي والأذكار والأربعين النووية وملف الأذان، ولا تُستبدل بخدمات خارجية أثناء الإغلاق.

تعتمد مواقيت الصلاة والقبلة على الحساب المحلي ومصدر الموقع الحالي من الولاية أو GPS، مع بقاء اختيار المستخدم محفوظًا ومتزامنًا بين الصفحات.

يظل الأذان اختياريًا ويُشغّل يدويًا بعد تفاعل المستخدم، ولا يُفرض تشغيل الصوت تلقائيًا دون إذن المتصفح.

تظهر وحدة رمضان الشرطية داخل شهر رمضان الهجري فقط، وتبقى مخفية خارجه.

لا حذف أو إعادة تسمية أو إعادة هيكلة إلا بدليل من Analyze على مشكلة مؤكدة، وبأصغر تغيير يمكن اختباره.

## بوابة التغيير

لا يبدأ Implement قبل تقرير Analyze وموافقة المستخدم الصريحة. ولا يتم رفع نسخة جديدة قبل اجتياز الاختبار الشامل والتحقق من عدم وجود أخطاء Console أو 404.
