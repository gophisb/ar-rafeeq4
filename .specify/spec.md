# مواصفة إغلاق الرفيق 4

## الهدف

إثبات أن الرفيق 4 نسخة مستقرة ومختبرة وقابلة للنشر، مع الحفاظ على الوظائف والهوية والبنية القائمة.

## معايير القبول

| المجال | معيار القبول |
|---|---|
| الصلاة | تُحسب المواقيت من الولاية أو GPS، وتعمل الساعة والعد التنازلي وانتقال اليوم. |
| الأذان | يعمل الاختبار اليدوي، ويبقى التشغيل التلقائي اختياريًا، ويُحمّل الملف المحلي. |
| القبلة | يعمل السهم مع مستشعر الهاتف، وتظهر الكعبة عند المحاذاة، ويكون الاهتزاز اختياريًا. |
| القرآن | تُحمّل 114 سورة و6236 آية محليًا، ويعمل الانتقال إلى آية اليوم. |
| التفسير | يرتبط تفسير السعدي بالآيات المحلية دون مراجع خارجية. |
| الأذكار | تظهر كل الأذكار وتبويبا الصباح والمساء، وتعمل العدادات والبحث. |
| النووية | تُحمّل الأحاديث المحلية وتعمل الصفحة والتنقل. |
| الموقع | يتزامن الموقع المختار أو GPS مع الصلاة والرئيسية والقبلة. |
| رمضان | تظهر بطاقة الإمساك والإفطار داخل رمضان فقط وتبقى مخفية خارجه. |
| PWA | يُسجّل Service Worker الحالي ويخزّن الملفات اللازمة للعمل Offline. |
| الجودة | لا أخطاء JavaScript أو موارد 404 في المسارات والصفحات الأساسية. |

## خارج النطاق

لا يتضمن الإغلاق تصميمًا جديدًا أو إضافة ميزات دينية جديدة أو تغيير مصادر البيانات أو إعادة بناء الراوتر أو محرك الصلاة دون دليل تحليلي.
