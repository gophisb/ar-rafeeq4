# ADR-0002 — خريطة الجزائر: الإصدار الأول الآمن

## القرار

إضافة خريطة الجزائر كميزة مستقلة داخل فرع الخريطة، مع:

- عرض الجزائر كاملة عبر OpenStreetMap عند توفر الإنترنت.
- تحديد GPS من الجهاز.
- البحث عن أماكن العبادة القريبة عبر بيانات OSM.
- حفظ آخر نتائج المساجد في `localStorage` لتظهر عند انقطاع الشبكة.
- عدم اختراع اسم المسجد أو بياناته؛ الحقول الناقصة تعرض بوضوح.
- إبقاء الأذان والقرآن والمحتوى الديني خارج نطاق تعديل الخريطة.

## لماذا ليست الخريطة الكاملة Offline داخل APK الآن؟

ملف الجزائر الخام من Geofabrik يقارب 286MB قبل تحويله إلى صيغة عرض داخلية، كما أن الخرائط والبحث والتوجيه تحتاج طبقة Mapsforge/BRouter وبيانات فهرسة إضافية. وضع ذلك في APK الآن سيزيد الحجم والتعقيد ويعرض الوظائف الحالية للخطر.

سيكون الإصدار التالي تنزيل منطقة Offline اختيارية، لا جزءاً إجبارياً من APK الأساسي.

## الثبات

- إذا انقطع الإنترنت: تبقى صفحة الخريطة وGPS والنتائج المحفوظة متاحة، مع إظهار حالة واضحة بدل شاشة فارغة.
- إذا لم يمنح المستخدم إذن الموقع: لا تتعطل بقية الصفحات.
- لا يعتمد تشغيل القرآن أو الأذان على الخريطة.
- مصدر البيانات: OpenStreetMap contributors، الترخيص ODbL 1.0.
